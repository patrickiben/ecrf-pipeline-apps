eCRF Pipeline Apps

Four independent Streamlit apps that read clinical eCRF extracts and write audit-ready outputs: auto-coding of adverse-event verbatims, PII/PHI flagging and redaction, participant safety and discontinuation risk scoring, and data anomaly and drift detection. Each app is a separate program with its own audit log, so a run can be reproduced from its audit alone.

Synthetic data only. Everything bundled with these apps is synthetic: no real patients, no real study and no licensed dictionary. The demo dictionary uses 99-prefixed placeholder codes; it is not MedDRA.

Try a hosted demo

Each app runs as its own Streamlit Community Cloud deployment in hosted mode: every data input is locked to the bundled synthetic cut, outputs go to a per-session temporary folder, a banner says so on every page, and the audit records hosted_mode=true. For real data, run the apps locally (see the README).

  • Coding app (meddra_app.py): MedDRA-style auto-coding of adverse-event verbatims
  • PHI app (phi_app.py): PII/PHI flagging and redaction
  • Risk app (risk_app.py): participant safety and discontinuation risk scoring
  • Anomaly app (anomaly_app.py): numeric outliers, distributional drift and text outliers

Each opens on the bundled synthetic sample data; click Execute to run it. An app that has been idle may take about 30 seconds to wake up.

The four apps

The coding, PHI and risk apps read the same synthetic cut folder without interfering; the anomaly app reads its own longitudinal demo, because drift needs a time axis. All four accept CSV, and SAS .sas7bdat when pyreadstat is installed.

Auto-coding

meddra_app.py

Reads
The one verbatim column you select (AETERM or a synonym), plus a dictionary as a flattened CSV or an .asc release.
Writes
ae_coded.csv (top three candidates per verbatim, with the LLT to SOC path) and audit_log.csv.

PII/PHI redaction

phi_app.py

Reads
Every non-numeric column, found by content rather than by name. No dictionary.
Writes
phi_flags.csv (one row per scrubbed span), sanitized/<domain>.csv and audit_log.csv.

Risk scoring

risk_app.py

Reads
Safety domains (ae, lb, eg, vs, pe), classified by content and scored against built-in [SI] criteria. No SAP file.
Writes
risk_scores.csv (safety and discontinuation scores with contributing factors) and audit_log.csv. Decision support, not a clinical determination.

Anomaly and drift

anomaly_app.py

Reads
Longitudinal files aligned by USUBJID: numeric columns, plus optional visit, lab/site and free-text columns.
Writes
anomalies.csv, drift.csv, lab_drift.csv, lab_compare.csv, text_anomalies.csv and audit_log.csv.

The four-tier chain

Every app runs the same discipline: four tiers in sequence, each handing named, readable columns to the next, so a decision is a row of numbers a reviewer can inspect and its threshold is a parameter a reviewer can move.

  1. Tier 1, intake. Aligns each row to its subject, copies every value through unchanged (missing stays missing) and locates the columns to read by content.
  2. Tier 2, retrieval and extraction. Proposes and measures: candidate dictionary terms, typed identifier spans, or per-subject signals. It decides nothing.
  3. Tier 3, context and calibration. Adds calibrated probabilities, an ambiguity score, aggregate risk scores or drift distances.
  4. Tier 4, decision. Applies an explicit rule to the earlier tiers' columns only: the auto-commit gate (default 0.88), the redaction gate (default 0.85), or the risk and anomaly categories.

Stand-in [SI] versus real

No trained weights ship with this repository, so the model tiers run as labeled deterministic stand-ins, tagged [SI] in the banner and in every audit row, with the same output columns the real components would produce. Installing the real runtimes (open-source Needle3 and Laya, hnswlib, XGBoost) flips the banner tier by tier; if a trained artifact is present but its runtime is missing, the app stops rather than substitute a stand-in. Optional packages also turn on real paths in the anomaly app: scikit-learn adds an Isolation Forest, and POT with scipy runs Sinkhorn optimal-transport drift.
